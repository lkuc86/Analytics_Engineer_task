# Publish the candidate repository

Suggested repository: Analytics_Engineering_task, under your GitHub account.

1. Create an empty public repository and upload the contents of this folder to its root, keeping subdirectories intact. Alternatively initialize Git locally, commit, add the GitHub remote, and push main using your authenticated Git client.
2. For the task webpage, open Settings > Pages and choose Deploy from a branch, main, / (root). The candidate page is index.html. Confirm the published URL in GitHub before sharing it.
3. Keep the separate reviewer ZIP private. Never upload its expected results or rubric to the public candidate repository.

The repository is self-contained and uses no external website assets. GitHub publication has not been performed by this package.
